# Armor Adventure - WIP/Alpha

Welcome to Armor Adventure. This mod adds a new upgraded version of the mech armor to the game, assembled through an epic "quest" that will require you to visit all five base planets and complete various tasks.

The true power of the armor will only become apparent with additional planet mods installed. Right now there are tie-ins with the following:
 - Rabbasca
 - Castra Prime
 - Moshine
 - Panglia

This mod is in an **"extreme alpha"** state and is NOT polished. The icons are terrible placeholders and somme entities look especially goofy. Basically, I am looking to see if there is actual interest in the mod before I bother creating icons and walkthroughs and stuff. I have some AI generated walkthrough information in the "docs" folder that I'm in the process of editing, which should give you an idea of how to proceed.

I do NOT promise any future support for this mod, and I do NOT promise no breaking changes. Elements may be removed, nerfed, made harder or easier to acquire.

Good luck!

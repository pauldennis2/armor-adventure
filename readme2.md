Erro's Extraordinary Armor Adventure, AKA ArmorQuest.

This mod is about going on a grand adventure/crafting challenge/quest to put together the ULTIMATE ARMOR. And then upgrade it.

Disclaimers
 - A lot of the features are pretty "overpowered" and can be used to break the game in some ways. I don't think anything I've created is too insane, and it's up to you to use it in a way that feels fun to you
 - This mod is intended for (modded) late game; you can try to complete the quests earlier, but if you aren't at the stage where producing legendary components is trivial, you're likely not going to get the full benefits.
 - Many features of this mod scale *heavily* with quality. If you don't have the capacity to make legendary components, some parts of the mod may actually feel under-tuned
 - If you're playing multiplayer, you will need to stay on the same planet IF you are trying to complete a "quest". The mod is generally not balanced with multiplayer in mind, though it should **work**, and if it doesn't please let me know


This mod is not for you if:
 - Any of the above disclaimers are dealbreakers


These things are not strictly necessary, but it will make your crafting journey easier if you have:

1. Bunnyhop engine from Rabbasca, easily get around on your quest. Fun mod generally
2. Ability to boost quality and productivity substantially beyond base game capabilities through modded beacons and/or modules
3. Killing a big demolisher should be no sweat
